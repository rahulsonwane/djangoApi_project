# 🚀 Django REST API – Plan Management

A simple and structured **REST API built with Django and Django REST Framework** for managing plan items.

This project demonstrates how to build RESTful APIs using Django REST Framework with serializers, class-based generic views, Django ORM, and API routing.

---

## ✨ Features

- 📋 List all plan items
- ➕ Create a new plan item
- 🗑️ Delete an existing plan item
- 🔄 RESTful API architecture
- 🧩 Django REST Framework serializers
- 🗄️ Django ORM for database operations
- ⚡ Class-based generic API views
- 🌐 API routing using Django URL configuration
